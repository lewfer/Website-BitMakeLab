# Project 4.03 - Build a Memory Game

![Robot](index.jpg){ align=right }

THIS WORKSHEET IS IN PROGRESS.

In this project you will build an electronic game. But it won't be screen-based!
You will construct it from various components and use a Microbit to code how the
game behaves.

The game is like the game called Simon that requires the player to remember a sequence of colours shown to them.  The sequence gets longer as the game progresses!
