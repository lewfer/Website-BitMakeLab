# Button: Make the part

To make a button:

1. Print this 3D part:
    [3D Design](../../3d-designs/pl12/index.md)

2. Fabricate this PCB design:
    [PCB Design](../../pcb-designs/button/index.md)

3. Purchase the following component(s):

    | Name                     | Purchase Links |
    | ------------------------ | ----------- |
    | 12mm tactile switch      | [RS](https://uk.rs-online.com/web/p/tactile-switches/6866777 ){target=_blank} |
    |                          | [Rapid](https://www.rapidonline.com/omron-tactile-pcb-switch-b3f-4000-12x12-flat-type-78-0286){target=_blank}  |

4. Solder the button on the PCB.

5. Hot glue the PCB onto the 3D part.
