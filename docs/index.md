# BitMake Lab Documentation

Welcome to the BitMake Lab documentation pages.  Here you will find the complete documentation for using, teaching and building the kit.

BitMake Lab is an open-source system for building projects with the BBC Microbit.  The system includes lots of physical components that can be plugged together to make robots, games and various machines.  The system can also be used together with other microcontroller boards such as the Raspberry Pi family and Arduino.

If you are new to BitMake Lab and the Microbit, start with the **<a href="projects/introduction"">Introduction</a>**.

For project worksheets, including student and teacher notes, dive into the **<a href="projects"">Projects</a>** pages.

For instructions on how to use individual components look in the **<a href="reference"">Reference</a>** section.

If you are looking to build the kit yourself, see the **<a href="make-the-kit">Make the kit</a>** section.

BitMake Lab has been created by **<a href="https://www.thinkcreatelearn.co.uk" target="_blank">Think Create Learn Ltd</a>**, a provider of creative computing education in London, UK.
