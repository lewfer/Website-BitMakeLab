# BitMakeLab Documentation

Welcome to the BitMakeLab documentation pages.  Here you will find the complete documentation for using, teaching and building the kit.

BitMakeLab is an open-source system for building projects with the BBC Microbit.  The system includes lots of physical components that can be plugged together to make robots, games and various machines.  The system can also be used together with other microcontroller boards such as the Raspberry Pi family and Arduino.

If you are new to BitMakeLab and the Microbit, start with the <a href="introduction/overview"">Introduction</a>.

For project worksheets, including student and teacher notes, dive into the <a href="projects/overview"">Projects</a> pages.

For instructions on how to use individual components look in the <a href="reference/overview"">Reference</a> section.

If you are looking to build the kit yourself, see the <a href="make-the-kit">Make the kit</a> section.
