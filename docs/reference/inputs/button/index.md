# Button
A button is a type of digital input device that allows a micro:bit or another electronic system to receive an instruction from a user. It is one of the simplest and most commonly used input devices in electronics and robotics.

A button works by detecting whether it has been pressed or released. Unlike an analogue input such as a potentiometer, which can provide many different values, a button generally provides two possible states:

Pressed → 1 / ON
Released → 0 / OFF
How Does a Button Work?

Inside a button is a simple electrical switch. When the button is not pressed, the electrical connection is open or in its inactive state. When the button is pressed, the switch changes state and allows the circuit to detect the change.

The micro:bit reads this change through one of its input pins.

For example:

Button released → No button press detected → 0

Button pressed → Button press detected → 1

The micro:bit can then use this information to perform an action programmed by the user.

Why Are Buttons Used?

Buttons are useful whenever you need a person to give a simple instruction to a program.

For example, a button can be used to:

Turn an LED on or off
Start or stop a motor
Make a robot move
Play a sound
Start a game
Change between different program modes
Increase or decrease a value
Trigger an event or action
